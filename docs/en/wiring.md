## Parts list

| Part | Used for |
|---|---|
| ESP32-S3 board with **OPI PSRAM** | the module itself (PSRAM holds the log and the 24 h chart history) |
| Quectel LG290P GNSS receiver (+ antenna) | position, RTK |
| Adafruit-compatible BNO085 board | heading/roll/pitch over UART-RVC |
| ADS1115 board | 16-bit ADC for the angle sensor and the current sensor |
| Steering angle sensor (potentiometer or Hall sensor on the steering axle) | wheel angle into ADS1115 channel 0 |
| ACS71240KEXBLT-030B3 current sensor (±30 A) | motor current into ADS1115 channel 1 |
| MCP23017 board | 16 outputs: sections, hydraulic lift, tram lines, geo-stop (as set in AgOpenWeb) |
| Cytron MD13S motor driver | drives the steering motor |
| W5500 Ethernet board (optional) | wired network instead of WiFi |
| WS2812 LED, steering push-button, work switch | status light and operator inputs |
| Fuse, hardware emergency stop, step-down converter | power (see below) |

## Power

- The ESP32 board and all logic run from a **stable 5 V** (a step-down converter from the vehicle supply is recommended).
  A weak USB supply caused IMU hangs on the prototype; an external converter fixed it.
- The **motor supply** (whatever your motor needs) connects only to the MD13S power terminals, **through the fuse and the
  emergency stop**. Share GND with the logic.
- Power the BNO085, ADS1115, MCP23017 and the current sensor from **3.3 V**.
- Spread GND / 5 V / 3.3 V over several header pins instead of one.

## Notes per module

- **IMU BNO085:** set the board to UART-RVC mode by tying **PS0 to 3.3 V** (solder it permanently). The sensor's SDA wire
  carries the UART data to **GPIO6**. RST to GPIO7 lets the module reset the sensor from the panel.
- **Angle sensor:** wire the sensor output to ADS1115 **A0**. Calibrate left/right end stops in the panel
  (**Calibration** tab) - see the [user guide](user-guide.md).
- **Current sensor:** output to ADS1115 **A1**, supply 3.3 V. After wiring, run the zero calibration (motor off).
- **Ethernet W5500:** leave RST unconnected on purpose (see the [pinout](pinout.md)). Switch it on in the panel (**Settings → Ethernet**) and restart.
- **Buttons:** steering button on GPIO15 and work switch on GPIO18 each connect the pin to **GND** when pressed/active
  (internal pull-ups are used).
- **Sections:** MCP23017 pins 0-15; the function of each follows the AgOpenWeb Pin Config (default: Sec1-16 on pins 0-15). Use relays/drivers suited to your loads - the MCP23017
  outputs are logic level only.
